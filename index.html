Calculation notes

All amounts are per stock unit. Shared shipment bills must be allocated to SKU quantities in the actual entry stages. LC margin and refundable container deposits are excluded from landed cost. Recoverable taxes can be excluded individually.

Duty rates shown are from your sample, pending HS-code and effective-date verification. Assessable value = Ass value x customs exchange rate + optional fixed BDT landing charge + optional fixed BDT PSI assessable value. PSI valuation changes the tax base, not the landed-cost expense directly. CD, RD and AIT use assessable value; SD uses AV + CD + RD; VAT and AT use AV + CD + RD + SD.
